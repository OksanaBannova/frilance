# FRILANCE

Сайт и админка используют один проект Supabase и общий файл `supabase-config.js`.
Сайт размещается на GitHub Pages из корня ветки `main`.

## Разработка

```sh
npm ci
npm run build
npm test
npm run preview
```

`script.js` — исходник React. После изменений выполните сборку и добавьте обновлённый
`site.js` в коммит. Браузер загружает готовый JavaScript без Babel.
Предпросмотр: http://127.0.0.1:4173/, админка: /admin.html.

## Supabase

Вход в админку выполняется учётной записью из **Authentication → Users**,
а не паролем от панели Supabase. Восстанавливайте пароль через Supabase Auth.

Исправление существующего проекта находится в `supabase/setup.sql`:
поле `portfolio_images.storage_path` и политика чтения метаданных Storage
для существующего администратора. Скрипт уже применён 12 октября 2026 года.
Повторный запуск безопасен. При переносе в другой проект поменяйте URL,
публичный ключ, идентификатор администратора и имя бакета.

Изображения загружаются в публичный бакет `portfolio-images`,
записи галереи сохраняются в `portfolio_images`.
Поддерживаются JPG, PNG, WEBP и GIF до 10 МБ на файл.
HEIC/HEIF с телефона нужно экспортировать в JPEG.

Изменения админки появляются после загрузки страницы, возврата к вкладке
или фоновой проверки каждые 30 секунд. На одном домене открытые вкладки
также получают уведомление о сохранении.

Публичный ключ допустим в клиентском коде. Секретные ключи и `service_role`
никогда не добавляйте в репозиторий.

## Проверено

Тесты проверяют выбор последних настроек, цены, пустое портфолио,
полную галерею, частичный отказ чтения и повторное сохранение метаданных.
Сайт проверен в браузере при ширине 320, 375, 768, 1024 и 1440 пикселей.
